# Hướng Dẫn Chạy Giao Diện GameBot (GUI)

## Câu lệnh khởi chạy

Mở Terminal (PowerShell hoặc CMD) tại thư mục dự án và chạy lệnh:

```powershell
python gui_app.py
```

---

## Các bước sử dụng

1. **Chuẩn bị:** Mở giả lập **LDPlayer** và vào sẵn màn hình **Guess Odd or Even (Chẵn Lẻ)** trong game.
2. **Khởi chạy GUI:** Gõ lệnh `python gui_app.py`.
3. **Cấu hình trên giao diện:**
   - Chọn cổng thiết bị ADB (hoặc để Auto kết nối).
   - Chọn chiến thuật cược: **EVEN (Chẵn)** hoặc **ODD (Lẻ)**.
   - Bật/tắt tuỳ chọn săn thêm **Phục Tùng C**.
4. **Bắt đầu:** Bấm nút **"Bắt đầu (Start)"** để bot tự động chạy.
5. **Dừng:** Bấm nút **"Dừng (Stop)"** bất kỳ lúc nào để ngắt hoạt động an toàn.
